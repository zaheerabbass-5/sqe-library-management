# SQE Library Management

## Project Description

The **SQE Library Management System** is a software project developed for the **Software Quality Engineering (SQE)** course.

The purpose of this project is to develop a simple Library Management System while applying software quality engineering practices throughout the development process.

The system will provide features for managing books, managing library members, and searching for books.

## Main Features

* Book Management
* Member Management
* Book Search

## Software Quality Activities

The project will use GitHub to support software development and quality activities, including:

* GitHub Issues for tracking tasks and bugs
* GitHub Projects for managing project work
* Labels for categorizing issues
* Testing and test case management
* Documentation
* GitHub Actions for automation
